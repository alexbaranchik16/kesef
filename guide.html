📖 התקנה וחיבור

1. העלאת האפליקציה לאינטרנט (פעם אחת, חינם) 2. התקנה בטלפון 3. חיבור אוטומטי להודעות מכאל ואמקס 4. דרכים נוספות למלא נתונים 5. גיבוי ופרטיות

1. העלאה לאינטרנט — GitHub Pages

כדי להתקין אפליקציה כזו בטלפון היא צריכה כתובת אינטרנט מאובטחת (https). GitHub Pages נותן את זה בחינם. רק הקוד עולה לשם — הנתונים הכספיים שלך לא, הם נשמרים רק בטלפון.

  1. היכנס ל-github.com ופתח חשבון (אם אין לך).
  2. לחץ + למעלה ← New repository. שם: kesef, סמן Public, ולחץ Create repository.
  3. בעמוד שנפתח לחץ על הקישור uploading an existing file.
  4. גרור לחלון את כל התוכן של תיקיית האפליקציה (הקבצים index.html, app.js… ואת התיקייה icons). את התיקייה apps-script לא חובה להעלות.
  5. לחץ Commit changes.
  6. עבור ל-Settings ← Pages. תחת Branch בחר main ו-/ (root) ← Save.
  7. אחרי דקה-שתיים תופיע למעלה הכתובת: https://USERNAME.github.io/kesef/ — זו האפליקציה שלך.
עדכון גרסה בעתיד: מעלים שוב את הקבצים שהשתנו לאותו מקום (Add file ← Upload files). האפליקציה בטלפון תתעדכן בפתיחה הבאה.

2. התקנה בטלפון

📱 אייפון

  1. פתח את הכתובת ב-Safari (דווקא Safari).
  2. לחץ על כפתור השיתוף ⬆️ ← הוסף למסך הבית ← הוסף.
  3. מעכשיו פותחים את "כספית" מהאייקון במסך הבית — היא נפתחת במסך מלא כמו אפליקציה רגילה, ועובדת גם בלי אינטרנט.

🤖 אנדרואיד

  1. פתח את הכתובת ב-Chrome.
  2. תפריט ⋮ ← התקנת אפליקציה (או "הוספה למסך הבית").
חשוב באייפון: השתמש תמיד באייקון שבמסך הבית ולא בכתובת בתוך Safari — לכל אחד מהם זיכרון נפרד.

3. חיבור אוטומטי להודעות

הרעיון: כל SMS מכאל/אמקס נשלח אוטומטית מהטלפון לגיליון Google Sheets פרטי שלך. האפליקציה מושכת משם את ההודעות בכל פתיחה, מזהה סכום, בית עסק ותאריך, ומסווגת לקטגוריה. כך זה עובד גם באייפון, שבו אפליקציות לא יכולות לקרוא SMS ישירות.

שלב א׳ — הגיליון (פעם אחת, מהמחשב)

  1. פתח sheets.new — נוצר גיליון חדש. תן לו שם, למשל "כספית הודעות".
  2. בתפריט: תוספים (Extensions) ← Apps Script.
  3. מחק את מה שכתוב בעורך והדבק את כל התוכן של הקובץ apps-script/Code.gs.
  4. בשורה const SECRET = '...' החלף למפתח ארוך משלך (אותיות ומספרים באנגלית, לדוגמה kx72hfQ93mzp41). שמור (Ctrl+S).
  5. לחץ Deploy ← New deployment ← בגלגל השיניים בחר Web app.
    • Execute as: Me
    • Who has access: Anyone
    לחץ Deploy.
  6. Google יבקש הרשאה: Authorize access ← בחר את החשבון ← אם מופיע "Google hasn't verified this app" לחץ Advanced ← Go to … (unsafe) ← Allow. (זה הסקריפט שלך, בחשבון שלך.)
  7. העתק את ה-Web app URL (מסתיים ב-/exec).
  8. באפליקציה: עוד ← הודעות אוטומטיות ← הדבק את הכתובת ואת המפתח ← שמור ובדוק חיבור. אמור להופיע "מחובר ✓".
לא למחוק שורות מהגיליון — הוא משמש גם כיומן גיבוי של כל ההודעות.

שלב ב׳ — אייפון: אוטומציה בקיצורי דרך

  1. פתח את אפליקציית קיצורי דרך (Shortcuts) ← לשונית אוטומציה ← + (או "אוטומציה חדשה").
  2. בחר הודעה (Message).
  3. ב-ההודעה מכילה (Message Contains) כתוב: כרטיס (מופיע בהודעות של כאל ושל אמקס). את "שולח" השאר ריק.
  4. סמן הפעל מיד (Run Immediately) ← הבא ← אוטומציה ריקה חדשה.
  5. הוסף פעולה: חפש קבל תוכן של URL (Get Contents of URL).
  6. במקום "URL" הדבק את כתובת ה-Web App.
  7. לחץ על החץ › להרחבה:
    • שיטה (Method): POST
    • גוף הבקשה (Request Body): JSON
    • הוסף שדה ← טקסט: מפתח key, ערך — המפתח הסודי שלך.
    • הוסף שדה ← טקסט: מפתח text, ובערך לחץ על המשתנה קלט קיצור הדרך (Shortcut Input). אם צריך, לחץ עליו ובחר תוכן (Content).
  8. לחץ סיום. מעכשיו כל הודעת חיוב נשלחת לגיליון ברקע, בלי שתצטרך לעשות כלום.
אם אתה רוצה לסנן יותר טוב, אפשר ליצור שתי אוטומציות: אחת עם "מכילה: כאל" ואחת עם "מכילה: אמריקן" או "אמקס" — לפי מה שכתוב בהודעות שאתה מקבל.

שלב ב׳ — אנדרואיד: MacroDroid (חינם)

  1. התקן MacroDroid מחנות Play ← Add Macro.
  2. Trigger: SMS Received ← Any number ← Content contains: כרטיס.
    אם ההתראות מגיעות מאפליקציית כאל/אמקס ולא כ-SMS: Trigger ← Notification Received ← בחר את האפליקציה.
  3. Action: HTTP Request ← Method POST ← URL: כתובת ה-Web App ← Content type: application/json ← Body: 
    {"key":"המפתח-הסודי-שלך","text":"[sms_message]"}
    (להתראות מאפליקציה השתמש ב-[notification_text] במקום [sms_message].)
  4. שמור את המאקרו ותן ל-MacroDroid את ההרשאות שהוא מבקש.

איך זה נראה ביום-יום

  • קנית משהו ← הגיעה הודעה ← היא נשלחה לגיליון.
  • פתחת את כספית ← העסקה נכנסה לבד עם קטגוריה, ומופיעה עם תגית חדש.
  • אם הקטגוריה לא נכונה — לוחצים על העסקה ומתקנים. האפליקציה לומדת ובפעם הבאה בית העסק הזה יסווג נכון.
  • הודעה שלא זוהתה תופיע כהתראה בדף הבית לטיפול ידני.

4. דרכים נוספות למלא נתונים

  • הוספה מהירה — כפתור +: סכום, בית עסק, קטגוריה. "שמור + עוד" לכמה ברצף.
  • הדבקת הודעות — מעתיקים הודעה (או כמה) מה-SMS ומדביקים ב"עוד ← הדבקת הודעות".
  • שיתוף (אנדרואיד) — בהודעה: לחיצה ארוכה ← שיתוף ← כספית.
  • אקסל מכאל / אמקס — באתר החברה: פירוט חיובים ← ייצוא לאקסל, ואז "עוד ← ייבוא אקסל". מתאים גם להשלמת חודשים קודמים. כפילויות מול הודעות שכבר נכנסו מזוהות ולא מסומנות.
  • האקסלים הקודמים שלך — אותו כפתור. צריך שורת כותרת עם עמודות: תאריך, תיאור (או בית עסק), סכום, ואם יש — קטגוריה (אם השם זהה לקטגוריה באפליקציה, הוא יישמר). סכום שלילי נקלט כהכנסה/זיכוי.

5. גיבוי ופרטיות

  • כל הנתונים נשמרים רק בטלפון שלך. אין שרת, אין חשבון.
  • פעם בחודש: עוד ← גיבוי לקובץ, ושמור ב-iCloud Drive / Google Drive. ככה אפשר לשחזר אם מחליפים טלפון.
  • ההודעות האוטומטיות נשמרות גם בגיליון הפרטי שלך ב-Google, שרק אתה (והסקריפט עם המפתח) יכול לגשת אליו.
  • "ייצוא לאקסל (CSV)" מוציא את כל התנועות לקובץ שנפתח באקסל.
